Prototype 1 · Offline HTML5 Map

Hello Offline 👋

This prototype demonstrates that the Service Worker and Cache API are correctly enabling offline functionality.

What this prototype demonstrates

  • The page loads even when the browser is in Offline mode.
  • Static files (HTML, CSS, JS) are cached using the Service Worker.
  • This is the foundation for the final offline HTML5 map application.

How to test it

  1. Open this page in Chrome (or any modern browser).
  2. Open DevTools → Network tab.
  3. Tick “Offline”.
  4. Refresh the page.
  5. If you can still see this page, the offline cache works.
